# Submission Checklist

This repository contains the complete xv6 assignment submission:

- Modified kernel source files, with explanatory comments at the implementation
  points.
- User programs: `memtest.c`, `vttest.c`, `pagetest.c`, and `pagereplace.c`.
- Terminal evidence in [`Screenshot/`](./Screenshot/).
- Implementation report in [`REPORT.md`](./REPORT.md).

Generated object files, binaries, disk images, dependency files, and assembly
 listings are excluded by [`.gitignore`](./.gitignore). They are recreated by
 `make` on the target machine.
